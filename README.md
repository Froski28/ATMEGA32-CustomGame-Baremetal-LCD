# ATMEGA32 Custom Game Driver

This is a custom circuit made to display the game with an LCD screen and control with a keypad. This was created using Microchip studio. To get this working, I created a custom LCD screen API.

## Parts
Microcontroller: ATMEGA32-16PU-ND \n
Screen: LCM-S01602DTR/A \n
Keypad: 96BB2-006-R \n
